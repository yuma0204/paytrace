# Paytrace — 1-minute pitch script

**0:00-0:12**

AI agents today cannot pay each other directly. They rely on subscriptions, API keys, or manual billing. This does not scale for machine to machine payments.

> 現在、AIエージェント同士は直接支払いができません。サブスクリプションやAPIキー、手動請求に頼っており、マシン間決済には適していません。

**0:12-0:28**

Paytrace solves this. Our SDK wraps any HTTP API with a pay per call paywall. Agents pay instantly in USDC on Solana, for every single request.

> Paytraceはこれを解決します。私たちのSDKは任意のHTTP APIに従量課金型のペイウォールを追加します。エージェントはSolana上でUSDCを使い、リクエストごとに即座に支払います。

**0:28-0:45**

Every payment creates a verifiable on chain receipt. Developers get a dashboard to track agent spend and earnings across all connected services.

> すべての支払いは検証可能なオンチェーン領収書として記録されます。開発者はダッシュボードで、接続された全サービスにおけるエージェントの支出と収益を追跡できます。

**0:45-0:55**

For long running tasks, we support simple escrow streaming payments, so agents pay continuously as compute happens.

> 長時間のタスクでは、シンプルなエスクローによるストリーミング決済を利用でき、計算処理の進行に応じて継続的に支払いが行われます。

**0:55-1:00**

Agentic AI is exploding right now. Paytrace gives it the native payment rail it needs, built fast and cheap on Solana.

> エージェント型AIは今まさに急拡大しています。Paytraceは、高速で低コストなSolana上に構築された、その機動的な決済レールを提供します。
